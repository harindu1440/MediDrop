## MediDrop – Smart Liquid Dosage System
#### An IoT-powered solution for accurate and timely liquid medicine dosing
### 📌 Overview

MediDrop is a smart device designed to measure and dispense liquid medicine doses accurately for children. It helps prevent underdosing and overdosing, while ensuring medicine is administered at the correct time.

The system combines IoT technology, microcontroller programming, and a mobile app to provide a seamless experience for parents and caregivers.

### 🎯 Problem Statement

Parents often face difficulties when giving liquid medicine to young children:

Forgetting scheduled doses

Overdosing or underdosing due to manual measurement

Lack of proper tracking of daily medicine intake

### 🎯 Aim

To provide a safe, accurate, and reliable solution for dispensing liquid medicine for children, ensuring correct dosage and timely reminders.

### ✅ Objectives

Accurately dispense liquid medicine

Prevent overdosing and underdosing

Send reminders/alerts when a scheduled dose is missed

Provide a daily medicine activity graph through a mobile app

### 🛠️ Methodology
#### 1. Technologies Used

Internet of Things (IoT) – device monitoring & remote alerts

Microcontroller Programming – using ESP8266

Flutter Mobile App – alerts, scheduling, and activity tracking

#### 2. Hardware Components

### 📱 App Features (Flutter)

Push notifications for missed doses

Daily medicine schedule

Activity graph for each day

User-friendly interface for adding medicine & schedules

### 📡 System Workflow

User inputs medicine type, dosage volume, and scheduled time

System dispenses the exact amount using a flow sensor & pump

If the user does not administer the dose on time, an alert is sent

Daily tracking is recorded and visualized inside the mobile app
